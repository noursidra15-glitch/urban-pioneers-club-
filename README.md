# URBAN PIONEERS CLUB — Website

A lightweight trilingual static website (Arabic, English, French) built with HTML, CSS and JavaScript.

## Run locally
1. Extract this folder.
2. Open `urban-pioneers-website` in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Edit `index.html`, `style.css`, and `script.js` as needed.

## Before publishing
- Replace the placeholder Instagram and Telegram links in `index.html` (`data-placeholder-link="instagram"` and `data-placeholder-link="telegram"`) with the club's official URLs.
- Confirm the club's approved specialty names, descriptions, and study paths against official university documents.
- Replace generic activity descriptions with real activities and real photographs when available.
- Test Arabic, English, and French language switching and check the site on a phone.

## Deploy on Netlify
1. Sign in to Netlify.
2. Choose **Add new site** → **Deploy manually** (the wording may vary).
3. Drag the extracted `urban-pioneers-website` folder (or its contents) into the deployment area.
4. Open the generated URL and test all sections and links.

No backend, admin panel, or database is included in this first version.
